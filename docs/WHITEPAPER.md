# 元界方舟 · MetaArk World — 白皮书

**版本** v1.0 · **定位** 区块链版「我的世界 + 模拟城市」

---

## 一、项目定位

元界方舟是一个以**经济体经营**为核心乐趣的链上世界。与纯打怪赚币的 GameFi 不同：
土地是产权、建筑是产能、玩家间的租赁与交易构成真实的经济循环。

三重吸睛点：
- **产权感** —— 地是你的、房是你的，全部 ERC-721/1155 上链
- **经营脑** —— 「原料 → 制造 → 零售」产业链，不是无脑挂机
- **社交性** —— 出租、办展、商会、治理共建

## 二、资产体系

### 2.1 土地（ERC-721）

| 属性 | 说明 |
|---|---|
| 区域 | 大陆（1.0x 稀有）/ 海域（1.5x）/ 空岛（2.5x） |
| 地形 | 平原（1.00x 产出）/ 火山（1.25x）/ 冰川（1.15x） |
| 人气值 | 100 起步，建筑与活动提升，上限 1000，影响产出与地价 |
| 建筑槽位 | 大陆 5 / 海域 3 / 空岛 6 |
| 租赁 | 日租 / 月租两档，出租期间土地锁定不可转让 |

### 2.2 建筑（ERC-1155）

- **功能型**：工坊 500 / 矿场 800 / 商店 700 / 农田 300 ARK，有日产出
- **装饰型**：雕像 1200 / 灯塔 1500 / 乐园 3000 ARK，提供大量人气
- **升级**：成本 = 造价 × (等级+1) × 1.6，产出线性 +50%/级 → 边际收益递减
- **衰败**：7 天宽限后每 7 天衰减 25%，维护费 20×等级 重置计时

### 2.3 材料（ERC-1155）

木材、矿石、能量核、设计图。合成配方：3 木材 + 2 矿石 → 1 能量核。

## 三、双币经济

| | $ARK 效用币 | $META 治理币 |
|---|---|---|
| 总量 | 无限但控产出（年通胀 ≤3%） | 固定 1 亿 |
| 获取 | 生产、任务、出租、活动 | 创世空投、分红、排行榜 |
| 消耗 | 建造、升级、维修、买材料 | 买稀有地、投票、精英区 |
| 保障 | Minter 白名单 + 链上通胀硬顶 | MAX_SUPPLY 常量，永不可增发 |

## 四、货币流与燃烧闭环

```
租客支付 2500 ARK
   ├── 房东 90%（2250）—— 可自由提现流转
   └── 协议 10%（250）—— 进入燃烧池

建造商店 700 ARK
   ├── 焚烧 5%（35）—— totalSupply 永久减少
   └── 金库 95%（665）

土地交易 5000 ARK
   ├── 卖方 100%（5000）
   └── 买方另付 3% 税（150）—— 进入燃烧池
```

**以上三组数字均由真实 EVM 测试精确验证，零误差。**

## 五、防崩盘四道闸

1. **土地稀缺**：硬顶 4096，按活跃度解锁（100 活跃玩家 → +10 格），不无限发地
2. **强制经营**：建筑衰败机制使「囤地不建」策略失效，持续产出需要持续投入
3. **通胀上限**：`inflation cap exceeded` —— 合约层面拒绝超额增发，任何人都无法绕过
4. **通缩对冲**：三重燃烧持续收缩流通盘，形成长期买压

## 七、地主收入模型示例

以一块估值 5000 ARK 的大陆地块为例：

1. 建造 1 座 5 级商店（累计投入约 700 + 2240×4 ≈ 9660 ARK）
2. 日产出 ≈ 45 × 3 × 地形加成 × 人气加成 ≈ 170 ARK/日
3. 挂日租 100 ARK，被租 30 天 → 收租 2700 ARK（扣协议 10% 前后见合约）
4. 土地人气从 100 涨至 400+，估值随人气升至 ~8000 ARK

**收入 = 生产 + 租金 + 地价增值，三重模型。**

## 八、风险与对策

| 风险 | 对策 |
|---|---|
| 代币抛压 | 建造/升级持续锁定并燃烧 ARK |
| 止损盘踩踏 | 衰败机制让土地价值需要维护支撑，投机盘天然减少 |
| 巨鲸垄断 | 地块按活跃度解锁 + 治理提案门槛 + 后续可加持土地税 |
| 治理攻击 | META 硬顶 + 精英区门槛（1000 META 才可提案） |
